Software

We develop and maintain several widely-used open-source modelling frameworks that form the backbone of aquatic biogeochemical research worldwide.

FABM

Fortran / Python / C

The Framework for Aquatic Biogeochemical Models provides a standardised interface for biogeochemical model components, enabling plug-and-play coupling with any physical host model.

↗ fabm.net ↗ GitHub

GOTM

Fortran / Python

The General Ocean Turbulence Model is a one-dimensional water column model for hydrodynamic and thermodynamic processes, with a comprehensive library of turbulence closure schemes.

↗ gotm.net ↗ GitHub

GETM

Fortran

The General Estuarine Transport Model is a three-dimensional baroclinic ocean model for coastal and estuarine applications, tightly coupled to FABM for biogeochemical simulations.

↗ getm.eu ↗ GitHub

parsac

Python

A Python package for parallelised sensitivity analysis and calibration of numerical models, with special support for GOTM and FABM-based simulations.

↗ GitHub

eat

Python / Fortran

The Ensemble and Assimilation Tool provides data assimilation capabilities for GOTM–FABM simulations, supporting ensemble Kalman filter methods for state and parameter estimation.

↗ GitHub
